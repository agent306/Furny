## Concerns
1. Spec defect: `02 §8.7` gives `quote_negotiations.status` as `string(16)` but the value `answered_with_revision` has 22 characters (and `answered_keep_price` 19), so 16 cannot work. I used `string(32)`, the `02 §0` default for enum columns, and pinned it in the schema test with a comment. A new sweep test asserts every B enum column is at least as long as its longest backed value. Spec `02 §8.7` (and the 19 log) should say 32.
2. `QuoteLineFactory` creates a TaxRate row by default (so that a discount line's `tax_rate_id null` is meaningful); tests that count tax rates must account for it.
3. No `FurnitureDesignFactory::lockedBy()` state was added (the brief does not list it); tests set `locked_by_order_id` with `forceFill`.
4. Delivered as one commit (feature plus Task 10 leftovers) because the A-test changes and the new FKs touch the same assertions.
