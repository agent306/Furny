## Deviations / concerns
1. `staff()` default role is `StaffRole::Support` (no 2FA); spec says `staff(string $role)` and the brief lists `staff()` with no args. Factory does NOT assign the spatie role (spatie tables/seeded roles arrive in Tasks 5/13); Task 13 should add the role assignment (afterCreating) to `staff()`/role states.
2. `NotificationPreferenceFactory::for($event, $channel)` overrides `Factory::for()`: a string event plus a `NotificationChannel` selects event/channel; anything else delegates to the framework `for($user)`. Works with Larastan level 8.
3. `termsPending()` also nulls `onboarded_at` (staff-created customers start with both null per 02 §1.1).
4. No model-level attribute defaults: `unit_system`, `length_unit`, `locale`, `timezone` defaults live in the DB (and factory); a model created via `new User([...])` + `save()` has them only after `refresh()`.
5. `phone_e164` has no normalising mutator ('' is not mapped to null); not requested by the brief. Phone normalisation belongs with the OTP/phone tasks.
6. Kit `sessions` table is absent until Task 5 (sessions use Redis; tests use the array driver), so nothing in P1 depends on it before then.
